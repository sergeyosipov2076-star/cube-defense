# Cube Defense

**Воксельная Tower Defense.** Защищай центральную башню от волн кубических врагов!

## 🎮 Как играть

1. Открой **МАГАЗИН** и купи сундук.
2. Из сундука выпадет случайная турель или баррикада по редкости.
3. Нажми **«▶ ИГРАТЬ»** и выбери уровень.
4. Тапни по панели внизу — выбери турель.
5. Тапни по клетке арены — турель поставится.
6. Нажми **«▶ НАЧАТЬ ВОЛНУ 1»** — мобы пойдут к башне.
7. Турели стреляют автоматически.
8. После волны жми **«▶ ВОЛНА 2 (+50 💎)»** — получишь бонус.
9. Продержись все волны — уровень пройден.

## ✨ Особенности

- **50 уровней** — каждый со своими волнами и сложностью.
- **10 боссов** — на уровнях 5, 10, 15, 20, 25, 30, 35, 40, 45, 50.
- **34 типа врагов** — кубики, бегуны, танки, копатели, вертолётчики, лекари, щитоносцы, драконы и другие.
- **35 турелей** — от базового стрелка до мифических пушек. У каждой турели свой ствол и текстура.
- **30 баррикад** — дерево, камень, железо, магия, лёд, золото, алмаз, незерит, обсидиан.
- **Сундуки 5 редкостей** — деревянный, серебряный, золотой, алмазный, мифический.
- **Система редкостей** — обычный, редкий, эпический, легендарный, мифический.

## 🕹 Управление

| Действие | ПК | Телефон |
|----------|----|---------|
| Выбрать турель | 1–9, A–G | Тап по панели |
| Поставить | Клик по клетке | Тап по клетке |
| Запустить волну | Кнопка «НАЧАТЬ ВОЛНУ» | Тап |
| Пауза | Кнопка ⏸ | Тап |

## 🛠 Технологии

- **Three.js** — 3D-графика.
- **Vite** — сборка проекта.
- **Vanilla JS** — без фреймворков.
- Все текстуры — **процедурные** (генерируются кодом).

## 📦 Установка

Игра работает в браузере — просто открой `index.html` или залей на любой хостинг.
